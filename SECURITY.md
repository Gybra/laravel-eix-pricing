# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.
Pre-release branches are not supported deployments.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for this repository and include reproduction
steps, affected versions and expected impact.

Never include production credentials, signed source URLs or private market
data in a report. Maintainers will acknowledge a complete report and
coordinate remediation and disclosure through the advisory.
